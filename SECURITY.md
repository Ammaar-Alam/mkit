# Security policy

## Reporting

Please use GitHub private vulnerability reporting for suspected security or privacy issues. Do not include authenticated page captures, copied practice content, cookies, access tokens, names, account identifiers, or score values.

## Scope

Security-sensitive guarantees include:

- No extension-initiated external network traffic
- No remote code
- Storage limited to sanitized MKit-authored study records
- No active-exam, answer-submission, reset, or account-state behavior
- Fail-closed masking when a completed-review layout is unsupported
- Exact, narrow page access and the `storage` permission only

## Supported versions

Security fixes are provided for the most recent tagged release. MKit 0.1.0 is currently in development.
